# pokeemerald-expansion

pokeemerald-expansion is ***a romhack base*** based off pret's [pokeemerald](https://github.com/pret/pokeemerald) decompilation project.

Branches:

    - ai_removed: AI was removed, player controls opponent
    - friend_battle: Playable romhack which uses ai_removed mechanics
    - inexperienced: My first romhack where XP gain is disabled
    - new-life: One of my older songs ported into the game
